# ClinIA / OdontoClinIA

- **URL**: https://www.clinia.com.ar/odontologia
- **Fecha de investigación**: 2026-11-22 (verificación del equipo: 2026-11-23)
- **Empresa / país**: Emprinet (ClinIA; OdontoClinIA es su módulo odontológico), Argentina (menciones a ReNaPDiS, ARCA, PUCO, RENAPER).
- **Segmento**: consultorios privados, clínicas PyME, centros municipales y hospitales públicos, cadenas. **Modalidad**: web con instancia y subdominio propio por cliente.

## Problema que resuelve

Software de gestión de salud con módulo dental y asistentes de IA, con integración a sistemas del Estado argentino.

## Usuarios objetivo

Instituciones de salud (privadas y públicas) más que odontólogo independiente.
